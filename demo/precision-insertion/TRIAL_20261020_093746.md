ordinary carried-object `reset`, which projected a phantom released key from
the empty wrist while also preserving the tabletop key as another obstacle.
The miss route now keeps one tabletop target and the frozen socket; normal
carried-object release still projects from the wrist. Second, reset built
its 10 cm lift request with planner FK **position only** and identity wrist
rotation. The stock Jacobian planner requires the requested start rotation
to match actual FK within 2°. On the saved stopped joint state, the wrist
rotation differed from identity by **103.359°**. The reset now uses the full
planner FK wrist pose. A read-only GPU replay of that saved arm state and
scene returned a valid 305-waypoint 10 cm lift with the corrected miss scene
and wrist pose. This replay cannot certify the shifted physical board pose.

the 541-point lift took 10.8 s at about 50 reference waypoints/s. The code
now restores stock `0.4` near/held speed and stock fixed-tick/full-sleep
playback. It retains the separate fix that lets a path reference catch up
when measured joints have advanced ahead of it, without skipping waypoints.
Speed was a plausible contributor to the contact; the saved run has no
approach controller trace, so it cannot exclude a pose or geometry error.
